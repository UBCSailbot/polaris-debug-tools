# Frontend Redesign Prototype

This folder is a standalone redesign concept for the Polaris desktop UI.

Important:

- It does not replace or modify the live `frontend/` implementation.
- It is not wired into Electron.
- It uses mocked bench data to demonstrate layout, hierarchy, and interaction direction.

Files:

- `index.html` - standalone prototype entry point
- `styles.css` - isolated visual system for the redesign
- `app.js` - lightweight interactions for view switching and mock updates

Preview:

1. Open [index.html](./index.html) in a browser.
2. Review the three workflows:
   - Bring-Up
   - Observe
   - Compare
3. If you like the direction, the next step would be selectively porting ideas into the real `frontend/` app.

Revert path:

- Delete this folder.
- No existing application files need to be restored.
